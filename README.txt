# Jyotish Academy homepage starter

## Files
- `index.html` — homepage structure and navigation dropdowns
- `style.css` — responsive visual design
- `script.js` — dropdown behaviour, mobile menu and basic English/Hindi text switch

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Firefox or another modern browser.
3. For local development, you can also run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Important
This is a front-end homepage prototype. The links currently navigate to homepage sections or placeholders. Login, student dashboard, course data, real simulators, bookstore inventory, cart, checkout, payment gateway, order management and admin functions require backend development and database integration.

The email address `hello@jyotishacademy.example` is a placeholder and must be replaced before launch.
The Google Fonts import requires an internet connection; system fonts will be used if unavailable.
